# MR. CUTZ — Premium Luxury Barber Website

MR. CUTZ is a cinematic luxury barber website crafted for a modern premium grooming experience. Designed with a dark noir-inspired aesthetic, smooth animations, and elegant editorial layouts, this website delivers a high-end digital presence for men’s grooming brands.

---

## ✨ Features

* Cinematic luxury UI/UX
* Fully responsive design
* Smooth scroll animations
* Premium dark theme
* Interactive hover effects
* Glassmorphism components
* Modern React architecture
* Optimized performance
* Mobile-friendly experience

---

## 🛠 Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* GSAP

## 🚀 Run Locally

Clone the project:

```bash
git clone https://github.com/your-username/mr-cutz.git
```

Go to project directory:

```bash
cd mr-cutz
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
